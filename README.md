# ChessBot_IITK

Welcome to **ChessBot_IITK**, a chess-playing bot developed as part of a project at the Indian Institute of Technology Kanpur (IITK). This Unity-based application allows users to play chess against an AI opponent, providing an interactive and engaging experience.

## Features

- **AI-Powered Gameplay**: Challenge an AI opponent that evaluates and makes optimal moves.
- **User-Friendly Interface**: Intuitive design for seamless interaction.
- **Cross-Platform Support**: Available for both desktop and WebGL platforms.

## Installation

To set up ChessBot_IITK on your local machine:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/Akshat20105/ChessBot_IITK.git
   cd ChessBot_IITK
   ```

2. **Open in Unity**:
   - Ensure you have [Unity](https://unity.com/) installed (version 2021.3.16 or higher recommended).
   - Open Unity Hub, click on "Add", and select the cloned project folder.

3. **Build the Project** (Optional):
   - For desktop builds, navigate to `File > Build Settings`, select your target platform, and click "Build".
   - For WebGL builds, select the WebGL platform in the Build Settings and proceed with the build process.

## Usage

1. **Starting the Game**:
   - Open the project in Unity and enter Play mode, or run the built application.

2. **Playing Against the AI**:
   - Use the mouse to select and move pieces.
   - The AI will automatically respond after your move.

## Project Structure

- **Assets/**: Contains all game assets, including scripts, prefabs, and graphics.
- **Build/**: Directory for compiled builds.
- **Library/**: Unity library files.
- **Logs/**: Log files for debugging.
- **Packages/**: Unity package configurations.
- **ProjectSettings/**: Project-specific settings.
- **UserSettings/**: User-specific settings.
- **WebGL Builds/**: Contains WebGL build files.
